# Контент курса: формат задач

Контент лежит в `backend/app/content/` в файлах `*.yaml` (по одному файлу на тему).
При старте сервера содержимое загружается в БД (upsert по `slug`) — можно править YAML и перезапускать.

## Структура файла темы

```yaml
slug: basics
title: Основы Python
icon: "🐍"          # эмодзи-иконка для карты
order: 1
lessons:
  - slug: vars
    title: Переменные
    order: 1
    tasks:
      - slug: greeting
        title: Приветствие
        difficulty: 1          # 1..3 (звёздочки)
        xp_reward: 20
        function: hello        # имя функции, которую вызывают тесты
        prompt_md: |
          ## Задача
          Напиши функцию `hello(name)`, которая возвращает текст
          `Привет, {name}!`

          **Пример:** `hello("Мир")` → `Привет, Мир!`
        starter_code: |
          def hello(name):
              # напиши код здесь
              pass
        hints:
          - "Используй f-строку: f'Привет, {name}!'"
          - "Можно и через конкатенацию: 'Привет, ' + name + '!'"
        tests:
          - input: ["Мир"]
            expected: "Привет, Мир!"
          - input: ["Python"]
            expected: "Привет, Python!"
```

## Правила

- `tests[].input` — список аргументов (JSON-типы: числа, строки, списки, словари, булевы).
- `tests[].expected` — ожидаемое **возвращаемое значение** функции (JSON-тип).
- Функция `function` должна быть определена в `starter_code`/коде ученика.
- Все тесты запускаются в изолированном процессе с лимитами:
  CPU 2 c, память 256 МБ, таймаут 3 c на тест.
- Ответ сравнивается по JSON-равенству (тип-к типу: `5 == 5`, `"5" != 5`).

## Типы задач (план развития)

- `type: function` (по умолчанию) — дописать функцию, автотесты выше.
- `type: output` (позже) — ученик пишет скрипт, проверяется stdout.
- `type: choice` (позже) — вариант ответа, без запуска кода.
- `type: fix` (позже) — в коде баг, нужно найти и исправить.

## Темы MVP (8 задач старта)

1. **Основы Python** — приветствие (строки), переменные-вычисление.
2. **Условия** — чётное/нечётное, максимум из трёх.
3. **Циклы** — сумма от 1 до n, факториал, печать звёздочки.
4. **Списки** — поиск максимума, реверс, сумма чётных.
5. *(вторая итерация)* словари, рекурсия, сортировки, графы.
