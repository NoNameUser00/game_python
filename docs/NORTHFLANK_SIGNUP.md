# Northflank: регистрация и деплой (замена HF Spaces)

> HF Spaces с Docker требует PRO-подписку ($9/мес) — бесплатно недоступно.
> Northflank Sandbox — бесплатная альтернатива: always-on, 2 сервиса + 1 БД,
> поддержка Docker-образов. Доступен из сети пользователя (проверено 2026-10-09).

## 0. Что получаем

- **2 бесплатных сервиса** (always-on, без сна) — один для нашего приложения
- **1 бесплатная БД** (PostgreSQL) — для данных игры
- **2 бесплатных cron-задачи** — например, для бэкапов
- Бесплатный SSL и кастомные домены
- Поддержка Docker-образов (наш `Dockerfile` подойдёт)

## 1. Регистрация (~5 минут)

1. Открыть **https://app.northflank.com/signup** (доступно из твоей сети).
2. Зарегистрироваться через **GitHub** (аккаунт уже есть) или по email.
3. Выбрать тариф **Sandbox** (бесплатный).
4. Подтвердить email.

⚠️ Если регистрация из РФ не работает (например, нужна карта или телефон) —
напиши мне, рассмотрим другие варианты (Beget VPS, Replit и т.д.).

## 2. Создание проекта и сервисов

После регистрации:

1. Создать **Project** (например, `game-python`).
2. Создать **Service** (тип: Docker):
   - Имя: `game`
   - Источник: GitHub-репозиторий `NoNameUser00/game_python` (или загрузка кода)
   - Dockerfile: корень репозитория (`Dockerfile`)
   - Порт: **7860** (наш образ слушает 7860)
   - Health check: `GET /api/health`
3. Создать **Database** (PostgreSQL):
   - Имя: `game-db`
   - Тип: PostgreSQL
   - Запомнить строку подключения (она понадобится для переменных окружения)

## 3. Переменные окружения (Service → Settings → Environment)

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | строка подключения к PostgreSQL (из шага 2) |
| `JWT_SECRET` | сгенерировать: `python3 -c "import secrets; print(secrets.token_urlsafe(48))"` |
| `FRONTEND_URL` | `https://<твой-домен>.northflank.app` (или временно `http://localhost:7860`) |
| `RUNNER_MODE` | `local` |
| `REQUIRE_EMAIL_VERIFICATION` | `0` (пока без SMTP) |

## 4. Проверка

1. Дождаться деплоя (статус **Running**).
2. Открыть `https://<твой-домен>/api/health` — должно вернуть `{"status":"ok"}`.
3. Открыть `https://<твой-домен>/` — должна открыться игра.
4. Зарегистрировать учителя, создать класс, проверить решение задачи.

## 5. Что прислать мне

После регистрации и создания сервисов прислать:

1. **Токен Northflank** (если понадобится для API) — или просто доступ к проекту.
2. **Строку подключения к PostgreSQL** (из шага 2).
3. **URL сервиса** (например, `https://game-xxx.northflank.app`).

Дальше я проверю работоспособность, настрою авто-деплой (если нужно) и дам
финальную ссылку на игру.

## 6. Если что-то пошло не так

- Сервис не стартует → вкладка **Logs** — прислать мне.
- БД недоступна → проверить строку подключения и права.
- Домен не открывается → проверить DNS и SSL в настройках сервиса.

## 7. Альтернативы (если Northflank не подойдёт)

- **Beget VPS** (РФ, ~200–500 ₽/мес) — полный контроль, Docker, но платно.
- **Replit** (бесплатно) — приложения засыпают, нестабильно для урока.
- **HF PRO** ($9/мес) — если готов платить за Docker Spaces.
- **Glitch** (бесплатно) — только Node.js, не подходит для Python.
