# Northflank: регистрация и деплой (замена HF Spaces)

> HF Spaces с Docker требует PRO-подписку ($9/мес) — бесплатно недоступно.
> Northflank Sandbox — бесплатная альтернатива: always-on, 2 сервиса + 1 БД,
> поддержка Docker-образов. Доступен из сети пользователя (проверено 2026-10-09).

## Что нужно от тебя (3 шага, ~5 минут)

### 1. Зарегистрироваться

Открыть **https://app.northflank.com/signup** → регистрация через **GitHub**
(аккаунт `NoNameUser00` уже есть) или по email. Тариф выбрать **Sandbox**
(бесплатный).

### 2. Привязать GitHub-аккаунт

В приложении Northflank: **Settings → Integrations → GitHub** → привязать
аккаунт `NoNameUser00`. Это нужно, чтобы Northflank мог собирать код из
репозитория `NoNameUser00/game_python`.

### 3. Создать API-токен

**Settings → API tokens → Create token** → скопировать токен (начинается с
`nf_...`). Дать ему права на создание проектов и сервисов (или все).

## Что сделаю я (после получения токена)

1. Создам **проект** `game-python`.
2. Создам **build service** (сборка из GitHub, ветка `main`, `Dockerfile` в корне).
3. Создам **deployment service** (запуск собранного образа, порт 7860).
4. Создам **PostgreSQL** addon.
5. Задам **секреты**: `JWT_SECRET` (сгенерирую), `DATABASE_URL` (из addon),
   `FRONTEND_URL`, `RUNNER_MODE=local`, `REQUIRE_EMAIL_VERIFICATION=0`.
6. Запущу сборку и деплой.
7. Проверю смоук-тестами по реальному URL.
8. Дам тебе финальную ссылку на игру.

## Что прислать мне

**API-токен Northflank** (`nf_...`).

⚠️ Токен — как пароль: он даёт полный доступ к твоему аккаунту Northflank.
Храним бережно; после настройки можно отозвать и создать новый.

## Если что-то пошло не так

- Регистрация не работает (нужна карта/телефон) → напиши мне, рассмотрим
  другие варианты (Beget VPS, Replit и т.д.).
- Не удаётся привязать GitHub → можно загрузить код вручную (zip), но это
  сложнее; лучше разобраться с привязкой.
- Сервис не стартует → вкладка **Logs** — прислать мне.

## Альтернативы (если Northflank не подойдёт)

- **Beget VPS** (РФ, ~200–500 ₽/мес) — полный контроль, Docker, но платно.
- **Replit** (бесплатно) — приложения засыпают, нестабильно для урока.
- **HF PRO** ($9/мес) — если готов платить за Docker Spaces.
- **Glitch** (бесплатно) — только Node.js, не подходит для Python.
