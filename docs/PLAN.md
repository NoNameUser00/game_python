# План проекта — статус (обновляю по ходу)

## Готово ✅

1. **Бэкенд MVP** — FastAPI, JWT-регистрация (пароли и письма — fastapi-users), карта тем, задачи, подсказки, XP/уровни, прогресс.
2. **Песочница** — изолированный subprocess: CPU 2 с, RAM 256 МБ, таймаут 3 с, stdin закрыт, понятные ошибки школьнику.
3. **Контент v2** — 6 тем × 4 задачи = **24 задачи** (`backend/app/content/*.yaml`, правится без кода; глубина — выбор пользователя, `docs/QUESTIONS.md` №9).
4. **Тесты** — 36 (API + классы + песочница + auth-сервис + режим учителя/достижения), `pytest`.
5. **Docker-стек** — compose: postgres + api + nginx (SPA + прокси + rate-limit). Локально: `docker compose up`.
6. **Дизайн-мокапы** — 3 варианта в `docs/design/` (открыть в браузере): A подземелье / B королевство / C космос.
7. **Фронтенд** React+Vite+CodeMirror — логин/регистрация, карта, экран задачи (Markdown + CodeMirror + подсказки + тесты), профиль. Сборка зелёная, e2e-прогон в браузере ✅.
8. **Регистрация по коду класса** (схему выбрал пользователь) — учитель создаёт класс и выдаёт 6-значный код; ученик регистрируется без почты; вход по имени/email; панель учителя `/classes` (создание классов, копирование кода, список учеников с прогрессом). E2e ✅ (детали: `docs/DECISIONS.md` § Регистрация и классы).
9. **Auth-сервис fastapi-users** (вариант выбрал пользователь) — пароли argon2, сброс пароля, подтверждение почты, письма dev→outbox/прод→SMTP; страницы `/forgot-password`, `/reset-password`, `/verify`; контракт API не изменился. 29 тестов, E2e ✅ (`docs/DECISIONS.md` №26–32).
10. **Расширенный режим учителя + лидерборд** (выбор пользователя, `docs/QUESTIONS.md` №7) — вкладки класса «Ученики / 🏆 Лидерборд / 📊 Статистика / 📋 Задания», сброс пароля ученику кнопкой 🔑, назначение задач классу, блок «Задания от учителя» на карте ученика. 36 тестов (+7), E2e ✅ (`docs/DECISIONS.md` №33–38).
11. **Достижения-значки** (выбор пользователя, №10) — 15 значков (первые решения, уровни, без подсказок, серия дней, «знаток темы»), считаются на лету без своей таблицы; сетка в профиле 🔒/открыто, тост «Новое достижение» на странице задачи (`docs/DECISIONS.md` №39).
12. **Название «Подземелья Python»** (выбор пользователя, №3; замена №49) — заменило заглушку «Питонята» во всём проекте (`docs/DECISIONS.md` №44).
