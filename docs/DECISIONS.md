## Решения по фронтенду (приняты субагентом при сборке)

## Регистрация и классы (2026-10-08)

> Схему «код класса от учителя, без почты детей» **выбрал пользователь**.
> Ниже — детали, принятые мной при реализации:

18. **Кто кем является**: `POST /api/auth/register` (по email) создаёт **учителя**, `POST /api/auth/register-class` (по коду класса) — **ученика** без email (`role` = teacher | pupil, поле `email` у учеников `NULL`).
19. **Вход**: единое поле `login` — email (учитель) или username (ученик). Почта ученикам не нужна.
20. **Код класса**: 6 символов из 31 символа без омнибусных букв (`ABCDEFGHJKMNPQRSTUVWXYZ23456789`, нет 0/O/1/I/L) ≈ 8.8×10⁸ вариантов; регистр не важен; проверка уникальности при генерации.
21. **Имя ученика** уникально **в пределах класса** (не глобально) — «Маша» в 7А и «Маша» в 7Б не конфликтуют.
22. **Класс** создаёт только учитель (`403` для учеников); у класса `teacher_id` без FK (иначе цикл FK users↔classes).
23. **Минимальный режим учителя** сделан сразу (без него схема с кодами нерабочая): панель `/classes` — создать класс, кнопка-копирование кода, список учеников с XP/решёнными. Расширенный режим и лидерборд — вопрос 7 в `docs/QUESTIONS.md`.
24. **Миграция dev-БД**: старый локальный `game.db` (email NOT NULL) автоматически пересоздаётся при старте (данные тестовые, контент подгружается из YAML). Прод-БД создаётся сразу с новой схемой.
25. **E2E проверено в браузере**: учитель → класс «7А» → код → ученик регистрируется по коду (в нижнем регистре нормализуется) → профиль «🏫 Класс: 7А» → вход ученика по имени → учитель видит учеников в панели. Консоль без ошибок. Тестов: 22 pytest (было 17, +5 на классы), smoke.sh зелёный.

## Auth-сервис: fastapi-users (2026-10-08)

> Вариант **A (`fastapi-users`) выбрал пользователь** из предложенного мной списка
> (поиск GitHub: fastapi-users 6.3k★ / authentik 26k★ / easyauth / Logto-Kratos).

26. **fastapi-users v15.0.5 (MIT)** встроен в наш бэкенд + адаптер **fastapi-users-db-sqlmodel 0.3.0**. Наш API-контракт (`register`, `register-class`, `login`, наш JWT на 7 дней) **не изменился** — fastapi-users даёт менеджера пользователей и новые роуты.
27. **Пароли**: argon2 через pwdlib (входит в fastapi-users) вместо самописного PBKDF2; есть авто-апгрейд хеша при входе. Старые PBKDF2-хеши больше не поддерживаются — локальная dev-БД пересоздаётся автоматически (миграция по набору обязательных колонок `users`), тестовые данные восстанавливаются регистрацией.
28. **Письма** (`app/email.py`): задан `SMTP_HOST` → отправка через SMTP (в отдельном потоке); не задан (dev) → JSON-по-строчно в `EMAIL_OUTBOX` (`backend/outbox.log`, git-игнор `*.log`) — так ссылки видны локально и их читают тесты. Настройки: `SMTP_HOST/PORT/USER/PASSWORD/FROM/STARTTLS`, `FRONTEND_URL` (откуда берутся ссылки в письмах), `REQUIRE_EMAIL_VERIFICATION` (по умолчанию 0 — подтверждение не блокирует вход; включить на сервере с настроенным SMTP).
29. **Синтетический email ученика**: fastapi-users требует уникальный email у всех — ученик получает внутренний адрес `pupil-{hex}@pupils.pitonyata.ru` (API отдаёт `email: null`, письма на него не уходят, `is_verified=true` — «верифицировал» код класса от учителя).
30. **Роуты fastapi-users** подключены под `/api/auth`: `forgot-password` (202, маскирует существование почты), `reset-password`, `request-verify-token` (202), `verify`. Английские коды ошибок фронт переводит на русский.
31. **Новые страницы фронта**: `/forgot-password` (ссылка «Забыли пароль? 🔑» на входе), `/reset-password?token=…`, `/verify?token=…` (авто-подтверждение по ссылке).
32. **Тесты и E2E**: 29 pytest (22 старых зелёные без изменений контракта + 7 новых на сброс/верификацию через outbox), smoke.sh зелёный; в браузере пройден полный цикл: «забыли пароль» → письмо → новый пароль → вход новым паролем → ссылка верификации → «Почта подтверждена ✅», консоль без ошибок.

## Расширенный режим учителя и лидерборд (2026-10-08)

> Выбор пользователя (`docs/QUESTIONS.md` №7): **«Лидерборд + расширенный режим»**.

33. **Лидерборд класса** `GET /api/classes/{id}/leaderboard`: места по XP ( tie-break — решённые задачи, потом имя), медали 🥇🥈🥉 в UI. Видят **учитель-владелец и ученики этого класса** (403 для чужих) — глобального лидерборда нет, только внутри класса (приватность).
34. **Статистика класса** `GET /api/classes/{id}/stats` (только владелец): число учеников, активные за 7 дней, средний XP, «решено задач-учеников X из N», прогресс-бары по темам + счётчик по каждой задаче.
35. **Сброс пароля учителем** `POST /api/classes/{id}/students/{sid}/password`: кнопка 🔑 в списке учеников (дети часто забывают пароли, а почты у них нет → «забыли пароль» им недоступен). Хешируется тем же argon2 (`fastapi-users.password.PasswordHelper`), старый пароль перестаёт работать.
36. **Задания учителя** (новая таблица `assignments`): `POST/GET /api/classes/{id}/assignments`, `DELETE /api/assignments/{id}`, ученик `GET /api/assignments` (плюс флаг `completed`). Учитель выбирает тему → задачу → «📌 Назначить», видит «✅ N из M», может убрать (✕).
37. **UI панели учителя** — вкладки в карточке класса: «👥 Ученики / 🏆 Лидерборд / 📊 Статистика / 📋 Задания»; у ученика на карте появляется блок «📋 Задания от учителя» (клик → задача; статус «▶ делать / ✅ сделано»).
38. **Тесты/E2E**: 36 pytest (+7 в `tests/test_teacher_mode.py`: доступ по членству, порядок мест, статистика, флоу заданий, сброс пароля, достижения), в браузере пройдены все 4 вкладки, назначение задачи глазами ученика и решение её; консоль без ошибок.

## Достижения (2026-10-08)

> Выбор пользователя (`docs/QUESTIONS.md` №10): **«+ достижения»**; жизни/энергия — не нужны.

39. **Значки без своей таблицы**: 15 достижений считаются **на лету** из прогресса и истории отправок (`app/achievements.py`) — нет риска рассинхрона после правок БД, состояние всегда производное от данных. Правила: первая задача, 5/10/20 задач, уровни 3 и 5, 3 задачи без подсказок, решение первой же отправкой, серия из 3 дней подряд, «🎓 Знаток темы» × 6 (все задачи темы). `GET /api/me/achievements` → все значки с флагом `unlocked`; в ответе на submit — `new_achievements` (только реально открытые этой отправкой), фронт показывает тост «Новое достижение…», сетка 🔒/открыто — в профиле.
