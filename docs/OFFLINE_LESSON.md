# Офлайн-урок: игра в классе без интернета

> Отвечает на `docs/QUESTIONS.md` №12 (план п.15). Проверено 2026-10-09:
> после сборки образов стек поднимается без сети (`docker compose up --no-build`).

## Идея

Вся игра (React-фронтенд, FastAPI, база, **шрифты и 31 задача**) лежит в
Docker-образах на компьютере учителя. Если образы уже собраны — интернет в классе
не нужен вообще: код учеников проверяется прямо на компьютере учителя.

## Что нужно

- Компьютер учителя с **Docker** и **Docker Compose**.
- Один раз дома, с интернетом — собрать образы (ниже).
- Компьютеры учеников — обычные, с браузером (клиенты подключаются по локальной сети).

## Подготовка (дома, один раз)

```bash
cd game_python
docker compose build              # собирает образы api и web
docker pull postgres:16-alpine    # образ базы
docker compose up -d              # прогрев и проверка
```

Открыть **http://localhost:8080** (или свой `WEB_PORT` из `.env`) — должен
появиться экран входа. Затем `docker compose down` — образы останутся локально.

**Проверка «без интернета»:** отключить сеть и выполнить `docker compose up -d` —
всё поднимется, потому что образы уже есть.

## Если компьютер в классе — другой

На домашнем ПК упаковать образы:

```bash
docker save game_python-api game_python-web postgres:16-alpine | gzip > game_python_images.tar.gz
```

Перенести `game_python_images.tar.gz` и папку проекта на школьный ПК, затем:

```bash
docker load < game_python_images.tar.gz
docker compose up -d
```

## На уроке

1. `docker compose up -d`
2. Открыть `http://localhost:8080`, зарегистрировать **учителя**, создать класс,
   скопировать **код класса**.
3. Ученики на своих компьютерах открывают `http://<IP-учителя>:8080`
   (IP узнать: Linux/macOS — `hostname -I`, Windows — `ipconfig`;
   в брандмауэре разрешить порт `8080`).
4. Ученики регистрируются **по коду класса** и решают задачи — проверка кода,
   XP, лидерборд работают локально, без внешнего интернета.
5. Письма не отправляются (dev-режим, outbox) — и не нужны.

## Остановка и данные

| Команда | Что делает |
|---|---|
| `docker compose stop` | пауза, данные целы |
| `docker compose down` | остановить, том с данными (`pgdata`) сохраняется |
| `docker compose down -v` | ⚠️ остановить **и удалить данные** |

Резервная копия прогресса:

```bash
docker compose exec db pg_dump -U game game > backup-$(date +%F).sql
```

Восстановление:

```bash
cat backup-2026-10-09.sql | docker compose exec -T db psql -U game -d game
```

## Полезно знать

- Порты по умолчанию: **8080** (игра) и **8000** (API). Если заняты — задать в
  `.env` (`WEB_PORT`, `API_PORT`; пример — `.env.example`). Это актуально, если
  на компьютере уже что-то слушает эти порты (как в нашей рабочей среде — Nextcloud на 8080).
- Пароль локальной базы — `game-local`; наружу база не выходит.
- Песочница кода изолирована: лимиты 3 с / 256 МБ / 2 CPU, stdin закрыт, **сеть отключена**
  (`DECISIONS.md` №53).
- Первый старт занимает ~10 с; таблицы создаются автоматически.
