# Настройка SMTP (письма на публичном сервере)

> План п.16. Сейчас письма попадают в `outbox.log` (dev-режим), а
> `REQUIRE_EMAIL_VERIFICATION=0`. Чтобы письма реально приходили на почту
> (подтверждение регистрации, сброс пароля) — задайте SMTP в **Variables and
> secrets** пространства HF и включите верификацию.

## 1. Что нужно от почтового провайдера

Любой SMTP с логином/паролем. Из России надёжнее всего:

| Провайдер | SMTP-сервер | Порт | Шифрование | Пароль |
|---|---|---|---|---|
| Яндекс | `smtp.yandex.ru` | `465` | SSL | **пароль приложения** (id.yandex.ru → Пароли приложений) |
| Яндекс | `smtp.yandex.ru` | `587` | STARTTLS | **пароль приложения** |
| Mail.ru | `smtp.mail.ru` | `465` | SSL | **пароль приложения** (mail.ru → Безопасность) |
| свой домен/Selectel | по договорённости | `587` | STARTTLS | обычный или app-пароль |

⚠️ Обычный пароль от почты не подойдёт — нужен **пароль приложения** (у Яндекса
и Mail.ru это отдельная настройка безопасности). У Google/Gmail из РФ доступ
нестабилен — не рекомендуем.

## 2. Переменные окружения (HF Space → Settings → Variables and secrets)

| Переменная | Пример | Назначение |
|---|---|---|
| `SMTP_HOST` | `smtp.yandex.ru` | сервер |
| `SMTP_PORT` | `465` | порт |
| `SMTP_USER` | `pitonyata@yandex.ru` | логин (обычно = адрес отправителя) |
| `SMTP_PASSWORD` | `abcd efgh ijkl mnop` | пароль приложения |
| `SMTP_FROM` | `Подземелья Python <pitonyata@yandex.ru>` | отображаемый отправитель |
| `SMTP_STARTTLS` | `0` | `0` = SSL (порт 465), `1` = STARTTLS (порт 587) |
| `REQUIRE_EMAIL_VERIFICATION` | `1` | вход только после подтверждения почты |
| `FRONTEND_URL` | `https://логин.hf.space` | ссылки в письмах |

## 3. Проверка

1. Перезапустить Space (кнопка **Restart** на странице Space).
2. Зарегистрировать нового учителя → письмо с подтверждением должно прийти.
3. Если письмо не пришло:
   - вкладка **Logs** на странице Space — ищем `письмо (smtp)` или ошибку;
   - при любой ошибке SMTP приложение **не падает**: письмо складывается в
     `outbox.log` (в контейнере) — ссылку можно увидеть там;
   - убедиться, что порт `587`/`465` не блокируется сетью (HF Spaces исходящий
     трафик не ограничивает, но корпоративные прокси бывают).

## 4. Если SMTP настраивать не хочется

Оставьте `REQUIRE_EMAIL_VERIFICATION=0` и пустой `SMTP_HOST`. Тогда:

- регистрация работает без почты (по коду класса — ученикам почта не нужна);
- письма подтверждения/сброса пароля складываются в `outbox.log` (в dev-режиме
  ссылку можно посмотреть там же);
- подтверждение почты можно включить позже в любой момент.
