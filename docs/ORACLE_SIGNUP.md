# Oracle Cloud: подробная инструкция (регистрация + бесплатный сервер)

> Отвечает на `docs/QUESTIONS.md` №6. Основано на официальной документации Oracle
> (Always Free Resources, © 2026) и типовом процессе регистрации.
> Ссылка для старта: **https://www.oracle.com/cloud/free/**

## 0. Что мы получаем (и что НЕ спишется)

- **Oracle Cloud Always Free** — бесплатный навсегда, без карты для «подписки»:
  - **ARM-сервер: до 2 OCPU и 12 ГБ памяти** (shape `VM.Standard.A1.Flex`, гибко делим)
  - до 2 маленьких AMD-инстансов (`VM.Standard.E2.1.Micro`, 1 ГБ) — как запасной вариант
  - 200 ГБ дисков, 10 ТБ/мес трафика, лоад-балансер, объектное хранилище
  - Этого **с запасом хватает** на нашу игру (FastAPI + PostgreSQL + React за Caddy)
- ⚠️ **Важно:** при регистрации дают **триал $300 на 30 дней**. Это не подписка:
  если ничего платного не создавать, после 30 дней аккаунт сам станет «Always Free»,
  деньги не списываются. Платных ресурсов не трогать — и всё будет бесплатно.
- ⚠️ **Лимит ARM «навсегда» = 2 OCPU / 12 ГБ** (не 4/24, как было раньше у Oracle —
  актуально сверено по документации 2026). Разместим: **1 OCPU + 6 ГБ** — нашему
  приложению этого более чем достаточно.

## 1. Что понадобится заранее (~15 минут)

1. **Email** — обычный (Gmail/Yandex и т.п.), на него придёт код подтверждения.
2. **Телефон** — для SMS-кода или звонка (подтверждение личности).
3. **Карта Visa/MasterCard** с международными онлайн-платежами — только для
   **проверки личности** (Oracle делает авторизацию ~$1 и её отменяет;
   само по себе наличие карты не значит, что будут списания).
4. **Браузер** на компьютере (не телефон).

## 2. Регистрация — по шагам

1. Открыть **https://www.oracle.com/cloud/free/** → кнопка **«Start for free»
   / «Начать бесплатно»**.
2. Ввести:
   - **Email** (уникальный, раньше не использовался в Oracle);
   - **Имя / Фамилию** — как в паспорте (сверяют с картой);
   - **Страну** — в списке свою (если страны нет в списке или карту не
     принимают — остановись и напиши мне, разберём отдельно);
   - придумать **пароль** (записать!).
3. На почту придёт **код подтверждения** (6 цифр) — ввести в форму.
4. **Тип аккаунта**: «Individual / Личный» (не Company).
5. **Домашний регион (Home Region)** — см. шаг 3, выбрать сразу и тщательно.
6. **Подтверждение личности**:
   - номер телефона → SMS-код (или дозвон с кодом);
   - данные карты (номер, срок, CVV, адрес — как в банке).
7. **Ожидание активации**: обычно минуты, иногда до нескольких часов/суток,
   Oracle может попросить уточнить данные. Придут письма на почту —
   аккаунт готов, когда можно войти в консоль.

## 3. Выбор домашнего региона — САМОЕ ВАЖНОЕ

- **Регион нельзя изменить потом** (техподдержка — только в редких случаях,
  практически не меняют). Все ресурсы Always Free живут только в нём.
- Критерии: близость к России/СНГ (пинг), наличие бесплатных ARM-мест,
  юрисдикция.
- **Рекомендую (по убыванию):**

  | Регион | Код | Почему |
  |---|---|---|
  | **Germany Central (Frankfurt)** | `eu-frankfurt-1` | близко, стабильно есть места, классика |
  | **Turkey Central (Istanbul)** | `eu-istanbul-1` | близко, часто есть ARM-места |
  | **Netherlands (Amsterdam)** | `eu-amsterdam-1` | запасной вариант в ЕС |

- Если при создании инстанса выдаст «out of host capacity» — это не конец:
  подождать часы/дни или попробовать другой домен доступности (AD).
  Часто помогает терпение (см. §7).

## 4. Первый вход в консоль

1. **https://cloud.oracle.com** → вход по email/паролю.
2. При входе предложат **двухфакторную защиту** — рекомендую включить
   (коды из приложения-аутентификатора; показывать их нигде не надо).
3. Запомнить **Tenancy OCID** и **Home region** (видны в правом верхнем углу /
   в профиле) — пригодятся для доступа.

## 5. Создание сервера (инстанса) — кратко

*(Детально настроим вместе после регистрации — этот раздел, чтобы ты понимал порядок)*

1. Меню ☰ → **Compute** → **Instances** → **Create instance**.
2. **Name**: например `python-dungeon`.
3. **Image**: Ubuntu → **Ubuntu 24.04** (или 22.04) — подпись «Always Free eligible».
4. **Shape**: `VM.Standard.A1.Flex` → **1 OCPU, 6 GB RAM** (или 2/12 целиком).
5. **SSH key**: сгенерировать на своём ПК:
   ```bash
   ssh-keygen -t ed25519 -f ~/.ssh/oci_dungeon -C "oci"
   ```
   содержимое `~/.ssh/oci_dungeon.pub` вставить в поле «Add SSH keys»
   (или вставить готовый ключ через интерфейс). **Приватный ключ не показывать!**
6. **Networking**: поставить галку **«Create a virtual cloud network plus
   internet connectivity»** — Oracle сама создаст VCN, подсеть и интернет-шлюз.
7. **Boot volume**: 50 GB (вписывается в бесплатные 200 GB).
8. Create → дождаться статус **Running**, запомнить **public IP**.
9. Проверить связь с своего компьютера:
   ```bash
   ssh -i ~/.ssh/oci_dungeon ubuntu@<PUBLIC_IP>
   ```
10. **Firewall (Security list / доменная зона безопасности)**: открыть
    входящие порты **22 (SSH), 80 (HTTP), 443 (HTTPS)** — в настройках
    инстанса → «Edit rules»/VCN → Security Lists → Add ingress rules.

## 7. Ловушки Oracle (чтобы не испугаться и не переплатить)

- **«Out of host capacity»** — не хватает бесплатных ARM-мест в регионе.
  Ждать и повторять, пробовать другой AD. Платить не нужно!
- **Не создавать ничего с пометкой «Платно»/без метки Always Free-eligible** —
  особенно «Bare metal», GPU, крупные shapes. Ориентир: в консоли у
  Always Free-ресурсов есть бейдж **«Always Free eligible»**.
- **Простой инстанса может привести к его удалению**: если за 7 дней CPU,
  память и сеть были заняты <20%, Oracle вправе убрать ресурс. Лечится
  простым cron-«keepalive» (периодический пинг) — поставлю на сервере сам.
- **Порт 25 наружу закрыт** у всех облачных аккаунтов Oracle — почта пойдёт
  только через 465/587 (SMTP-провайдер). Это учтено для писем игры.
- **Триал $300/30 дней**: после него аккаунт станет Always Free, если ничего
  платного не создавать. Платёжные реквизиты остаются «на всякий случай»,
  списаний не будет.
- **Карта/страна не принимается** — напиши, что именно показывает (часто
  помогает другая карта или виртуальная карта банка).
- Проверить, что всё бесплатно: меню ☰ → **Governance & Administration** →
  **Limits, Quotas and Usage** — везде должны быть лимиты Always Free.
